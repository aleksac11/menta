# Smuvalicina Menta

Sajt radionice pozivnica za venčanja, rođendane i proslave.

## Objavljivanje na GitHub Pages

1. Na github.com napravite novi repozitorijum (npr. `smuvalicina-menta`), označen kao **Public**.
2. Kliknite **Add file → Upload files**, prevucite `index.html` (i ovaj README) i kliknite **Commit changes**.
3. Idite na **Settings → Pages**. Pod **Source** izaberite **Deploy from a branch**, zatim granu `main` i folder `/ (root)`, pa **Save**.
4. Posle minut-dva sajt je dostupan na `https://VAŠE-KORISNIČKO-IME.github.io/smuvalicina-menta/`.

## Izmena kontakt podataka

U fajlu `index.html` potražite blok `PODACI` (pri dnu, u `<script>` delu) i zamenite broj telefona i Instagram nalog.
